## Reading these results

- One machine, one run. Linux runs in WSL2 on the same hardware as Windows, not on a separate Linux host.
- Commercial libraries run on their free trial or evaluation, with any evaluation watermark masked before image comparison (see METHODOLOGY.md, section 2). PDFsharp 6.5 runs under its AGPL licence.
- Each library is configured as its vendor documents; the adapter code for every library is in [`harness/`](https://github.com/csharp-pdf/pdf-benchmarks/tree/main/harness). Vendors are invited to correct it.
- Prices are in [`pricing/`](https://github.com/csharp-pdf/pdf-benchmarks/tree/main/pricing), dated, from each vendor's page.
